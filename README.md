# A Little Graduation Surprise

A mobile-first, single-page graduation greeting for final-year students of the Department of Islamic Learning, University of Karachi.

## Updated interaction lock
The opening screen is locked in place when the site first loads. The visitor cannot scroll, swipe, use the mouse wheel, or use keyboard scroll controls to skip ahead. The later screens are also marked inert for keyboard and assistive-technology navigation. Only activating **Open your surprise** starts the envelope animation; the page unlocks after that reveal and then moves to the next scene.

## Features
- Pastel floral motion and CSS-drawn botanical details
- Click-to-open animated envelope
- “Look what you've done!” and “You did it — Graduation!” reveals
- English dua and closing signature: Shaikh Tahami — Software Engineer
- Mobile-first responsive layout, no build step, no external library/assets
- Keyboard focus states and reduced-motion support

## Preview locally
Open `index.html` in a modern browser.

## Publish as a live link
